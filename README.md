# ⚔️ 神葬アトリエ：交代制バトル＆育成工房

「神葬アトリエ：交代制バトル＆育成工房」は、Python（Streamlit）を用いて開発された、**自由な特徴カスタムと戦略的な交代制ターンバトルが楽しめる育成シミュレーションRPG**です。

プレイヤーはアトリエの錬金術師となり、3体の実験体を育成・強化し、次々と立ちはだかるダンジョンの試練（ボスと配下モンスターの群れ）に挑みます[cite: 4, 8]。

---

## 🌟 主な特徴 (Features)

- **🧪 自由な特徴カスタム（育成ルーム）**
  - 「生物種」（ドラゴン型、獣型、昆虫型、飛行型、水棲型）
  - 「主属性」（炎、氷、雷）
  - 「副属性」（植物、血、結晶）
  - 「武器種」（ロングソード、大鎌、銃、弓）
  - これらの組み合わせにより、自分だけの実験体を作り込み、ステータスや専用スキルを変化させることができます[cite: 8]。
- **🥣 育成・エサやりによるステータス強化**
  - 特製エサや素材調合により、HP・攻撃力・防御力をカスタム強化（上昇値の合計上限あり）[cite: 4, 8]。
  - バトル勝利やエサやりで経験値（EXP）を獲得し、ステージ1から最大ステージ4（神葬解放）まで進化します[cite: 4, 8]。
- **⚔️ 戦略的な交代制ターンバトル**
  - 3体の実験体によるパーティ制。前衛がピンチになったら「控えメンバーとの交代」や「回復魔法」を駆使してパーティを立て直せます[cite: 4, 8]。
  - スキルの威力（40%〜100%）に応じて、次に使用できるまでの**クールダウン（待機ターン）**が変動するタクティカルな戦闘システム[cite: 8]。
- **📖 図鑑コンプリート要素**
  - 最上位ステージ（ステージ4）に到達した実験体の組み合わせは図鑑に記録され、コンプリートを目指すやり込み要素も搭載[cite: 4, 8]。

---

## 🕹️ 遊び方 (How to Play)

1. **育成ルーム**: 3体の実験体（α, β, γ）の生物種や属性、武器種を選択して特徴を確定させます[cite: 4, 8]。
2. **素材調合・エサやり**: ゴールドを消費してステータスを強化し、経験値を稼いでステージ進化を目指します[cite: 4, 8]。
3. **戦闘ステージ出撃**: 
   - 初級、中級（①〜③）、上級（①〜③）、最上級の全8ステージから挑戦するダンジョンを選択[cite: 8]。
   - 配下モンスターを撃破したあと、強力なステージボスとの決戦に挑みます[cite: 4, 8]。
4. **完全クリア**: 最上級ステージ『アルカディアの王座』を制覇すると、完全クリア画面（お祝い演出）が解放されます[cite: 8]。

## 🛠️ 動作環境 & 必要ライブラリ (Requirements)

- Python 3.8+
- Streamlit
- Pillow (PIL)

### インストール方法
```bash
pip install streamlit pillow
```
起動方法
ターミナル（またはWSL環境など）で以下のコマンドを実行してください。
```bash
streamlit run app.py
```
