# monsteregg
⚔️ 神葬アトリエ：交代制バトル＆育成工房Streamlitで構築された、自由な特徴カスタムと戦略的な交代制ターンバトルが楽しめるブラウザ育成RPGゲームです。🎮 ゲーム概要プレイヤーは錬金工房の主となり、3体の「実験体」を育成・強化しながら、数々のダンジョンや強敵が待ち受けるステージの制覇を目指します。生物種・属性・武器種の組み合わせによって実験体の姿や専用スキルが変化し、育成とバトルの両方を深く楽しむことができます。✨ 主な特徴・システム🧪 自由な特徴カスタム（育成ルーム）「生物種（ドラゴン型、獣型など）」「主属性」「副属性」「武器種」を自由に選択・確定できます。   成長段階（ステージ1〜4）が進むにつれて、外見ビジュアルや強力な固有スキルが解放されます。🥣 素材調合・エサやり（ステータス強化）資金と素材を使って実験体のHP・攻撃力・防御力をカスタム強化できます（上昇合計値に制限あり）。   バトルに勝利するとゴールドに加えて経験値（EXP）が獲得でき、パーティ全体の育成が進みます。   ⚔️ 交代制ターンバトル & スキルクールダウン配下モンスターとボスが待ち受ける全8ステージのダンジョンに挑戦。   威力（倍率）に応じてクールダウン（待機ターン）が変動する戦略的なスキル選択や、ピンチを救う「回復魔法」、控えメンバーとの「交代」を駆使して戦います。📖 図鑑コンプリート機能最大形態（ステージ4）に到達した実験体の組み合わせは図鑑に記録され、コンプリートを目指すやり込み要素も搭載。🚀 動作環境・必要ライブラリPythonがインストールされた環境で動作します。以下のライブラリが必要です。Python 3.8+StreamlitPillow (PIL)📦 インストール & 実行方法リポジトリをクローン、またはファイルをダウンロードします。必要なライブラリをインストールします。Bashpip install streamlit pillow
アプリケーションを実行します。Bashstreamlit run app.py
